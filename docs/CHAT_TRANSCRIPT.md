## WordPress conversion

### User

These websites, can I convert them to Wordpress?

### Assistant

Yes—but **not as a one-click conversion**.

This website is built with React, not WordPress. To move it to WordPress, you have two practical options:

- **Rebuild it in a WordPress theme or page builder**, such as Gutenberg, Elementor or Bricks. You can closely match the current design and edit pages through WordPress.
- **Develop a custom WordPress theme** based on this design. More work, but gives you tighter control and less reliance on a page builder.

The copy, images, colours, pricing and layout can carry over. Navigation, forms and other interactions need to be recreated.

**For your web-design business:** use this version as an approved design prototype, then rebuild in WordPress if clients need WordPress hosting and editing. Don’t promise a WordPress deliverable unless that rebuild is included in your price.

### In Claude
1. Create a separate **Project** for each website.
2. In Project knowledge, click **+ → GitHub**.
3. Connect your GitHub account and select the repository’s relevant files and folders.
4. Use **Sync** after changes to refresh Claude’s copy.

Claude can then use the uploaded code to understand the layout, colours, styling, content and functionality.

**But “all information” has limits:** GitHub doesn’t include our chat history, uncommitted research, private environment variables, hosting settings or live customer/database data unless explicitly added. Large repositories also need selective file loading.

The standard GitHub integration supplies code context; it doesn’t automatically deploy changes or convert the sites to WordPress.
